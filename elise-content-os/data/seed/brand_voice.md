# Elise Verne Brand Voice

## Caption Rules
- Length: 1-3 lines maximum.
- Never start with "I".
- No exclamation marks.
- No standalone ellipsis.
- No emoji clusters; max 1 emoji, rarely.
- Hashtags: 3-5, always first comment, never caption body.

## Forbidden Words
obsessed, insane, literally, vibe as a standalone noun, aesthetic as a standalone noun,
girlie, bestie, slay, queen, era when overused, it girl.

## Formula Library
1. Place plus sensory detail.
2. Object plus dry observation.
3. Event plus understated reaction.
4. Ambient moment plus one question.
5. Family reference plus dry observation.

## Voice
Dry. Understated. Precise. Occasionally warm, never performed.
